# Deep Govindvira — Software Development Engineer Portfolio

A modern, responsive, high-performance portfolio website built with **React 19** and **Tailwind CSS**.

---

## 🚀 Features

- **Modern Dark Aesthetic**: Ambient glow gradients, glassmorphism cards, and responsive micro-interactions.
- **Sticky Glassmorphism Navbar**: Dynamic active section indicator, quick navigation, and mobile drawer.
- **Interactive Hero Section**:
  - Profile image with animated multi-colored gradient ring.
  - Role highlights, status badge (*Upcoming SDE @ Zeus Learning*), social links (GitHub, LinkedIn, LeetCode, Email).
  - High-impact statistics bar.
- **About & Core Pillars**: In-depth background, engineering focus areas, and technical values.
- **Interactive Skills Taxonomy**:
  - Live search input for instant skill lookup.
  - Category filters (*Core CS*, *Languages*, *Backend*, *Databases*, *Frontend*, *Cloud & Tools*).
  - Highlighting key strengths with indicator dots.
- **Experience Timeline**:
  - **Zeus Learning**: Upcoming SDE with company logo, key focus areas, and tech stack badges.
  - **Decrypters Coding Club**: Core Committee Member role, Binary Beast Contest organization, and DSA mentorship.
- **Featured Projects Showcase**:
  - Filterable by category (*All*, *Full Stack*, *Backend*, *Systems*, *Frontend*).
  - Architecture highlights, tech pills, GitHub repository links, and demo triggers.
- **Education & Achievements**:
  - B.Tech in Computer Engineering from Dharmsinh Desai University (DDU).
  - Competitive programming & leadership highlights (HackerRank contest organization, 500+ problems solved, peer mentorship).
- **Direct Contact & Form**:
  - Instant one-click **"Copy Email"** button with feedback toast.
  - Interactive contact message form that integrates directly with standard mail clients.
- **Centralized Data Configuration**: All portfolio content (links, projects, experience, skills, social handles) is neatly managed in [`src/data/portfolioData.js`](file:///Users/dhiraj/Desktop/deep/github/react-portfolio/src/data/portfolioData.js).

---

## 🛠️ Tech Stack

- **Framework**: React 19
- **Styling**: Tailwind CSS 3.4
- **Icons**: Custom accessible SVG components (zero external dependency bloat)
- **Tooling**: Create React App, Webpack, Jest, React Testing Library

---

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm start
```
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### 3. Run Tests
```bash
npm test
```

### 4. Build for Production
```bash
npm run build
```
Creates an optimized, minified production build inside the `build/` folder.
